****************************************************** Manuel d'utilisation Gestion des Salles ***************************************************************


****************************************************************** client / visiteur *************************************************************************

Bonjour, lorsque vous entrerez dans l'application (link: https://gestion-des-salles-cpnv.web.app/), vous serez dans le menu de connexion pour pouvoir entrer.

Si vous cliquez sur les logos ou sur le nom de l'application, vous accéderez à une page où vous verrez toutes les salles, mais vous devrez vous connecter pour pouvoir réserver.
Pour créer un compte, il suffit de cliquer sur « créer un compte » et de remplir les champs vides. 
Une fois que vous aurez rempli tous les champs et cliqué sur « s'inscrire », un courriel de confirmation sera envoyé à votre adresse électronique afin de vérifier qu'il s'agit bien de vous.

Dès que vous aurez confirmé votre adresse électronique et que vous vous serez connecté à la page d'accueil, vous serez dirigé vers le tableau de bord où vous pourrez choisir de réserver une salles ou de consulter vos réservations.

Pour réserver une salles, il vous suffit de vous connecter à la page de réservation et de cliquer sur le bouton « réserver » pour la salles de votre choix, de choisir un jour et des éléments supplémentaires.

Pour gérer vos réservations, cliquez simplement sur « gérer les réservations » et vous verrez toutes vos réservations avec la possibilité de les modifier ou de les supprimer.

**************************************************************************** admin ***************************************************************************


En vous connectant, vous accéderez au tableau de bord où vous pourrez choisir d'afficher les réservations effectuées ou simplement les statistiques des salless.

Dans les réservations se trouvent toutes les salless que nous pouvons modifier ou supprimer.

Il est également possible d'ajouter des salles en cliquant sur le bouton « ajouter une salle ».

Dans les statistiques on peut voir la distribution des matériaux (on peut choisir le mois que l'on veut voir) et aussi en cliquant sur le bouton « change » on peut voir un graphique avec l'évolution de la réservation des salles par jour.
